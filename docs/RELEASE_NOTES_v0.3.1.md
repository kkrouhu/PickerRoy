# PickerRoy v0.3.1 — Release reliability and Apple V1 preparation

This patch release keeps the 0.3 feature set and makes the public release easier to trust and use.

- Keeps analysis pause, resume, safe cancellation, in-run queueing, personalized local taste learning, and direct/optimized export.
- Updates all three user manuals with the free V1.0, privacy-first, local-processing plan.
- Adds the native universal Apple project for macOS, iPhone, and iPad as a development preview. The downloadable desktop packages remain the existing standalone app for macOS and Windows.
- Adds a Privacy Manifest and minimum-permission Photos save flow to the native Apple target.
- Adds a lightweight all-features-available policy boundary for future monetization without StoreKit, subscriptions, IAP, paywalls, prices, or feature locks in V1.0.
- Updates the GitHub release workflow to current Node 24-compatible actions and a dedicated release uploader.

The installed desktop app does not need Codex, Python, a server, or a separate FFmpeg installation. The Codex Skill is an optional support bundle and is not the application itself.
