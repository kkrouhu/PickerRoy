# PickerRoy v0.3.0 - Your footage, your taste

This release makes long-video analysis controllable and turns everyday editing decisions into a real private personalization loop.

## Highlights

- Pause, resume, and safely cancel analysis on macOS and Windows.
- Add new videos while analysis runs; they stay in a clearly marked next-batch queue.
- More precise portrait and landscape ranking with explainable theme-aware aesthetic cues.
- Favorite, Keep, Reject, and A/B choices jointly train the next local preference model.
- New personalization progress and preferred-category summary in the Chinese interface.
- Direct export or optional optimized export with bounded pixel recovery and restrained tone, color, and sharpness enhancement.
- Updated Codex Skill with a privacy-preserving preference-profile script.
- Chinese, English, and bilingual PDF manuals included in the Release.

## Honest boundaries

Optimized export is not generative super-resolution and cannot recreate source detail that does not exist. Social popularity is a relative signal, not a promised like count. Theme-aware features are research-informed local engineering and are not presented as a newly scraped or newly trained social-media model.

## Desktop requirements

The standalone packages include Python, Qt, FFmpeg/FFprobe, OpenCV, and the offline IIPA model. Users do not need Codex or a development environment. A discrete GPU and an internet connection are not required for analysis.
