# PickerRoy v0.3.2 — Reliable downloads and modern Apple decoding

- Keeps every 0.3 feature: pause, resume, safe cancellation, queueing, local taste learning, and direct/optimized export.
- Uses Apple's current asynchronous AVFoundation image-generation API in the native macOS/iPhone/iPad project, and reports real decode failures instead of silently returning an empty result.
- Publishes the Chinese, English, and bilingual manuals with ASCII-only download filenames so GitHub can reliably create every release asset. The PDF contents remain fully localized.
- Keeps Apple App Store V1.0 completely free, with no StoreKit, subscription, In-App Purchase, paywall, price, purchase button, restore button, or feature lock.
- Keeps videos, frames, paths, and preferences on the user's device; no server or account is required for core processing.

The standalone desktop App works without Codex. The Codex Skill remains an optional support bundle for installation help, troubleshooting, and source-level improvement.
